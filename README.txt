KANTINBAROKAH — WEBSITE PEMESANAN & PROMOSI KANTIN SEKOLAH

Teknologi: HTML5, CSS3, JavaScript, LocalStorage, WhatsApp Click-to-Chat.

FILE:
- index.html
- style.css
- script.js

MENGHUBUNGKAN WHATSAPP PEMILIK:
Buka script.js dan cari:
const STORE={name:"KantinKita",whatsapp:"6281234567890",phoneDisplay:"08xx-xxxx-xxxx"};

Ganti whatsapp dengan nomor pemilik.
Nomor Indonesia 081234567890 menjadi 6281234567890.
Ganti phoneDisplay dengan nomor yang ingin ditampilkan.

EDIT MENU:
Semua menu berada pada array products di script.js.
Harga, nama, kategori, deskripsi, emoji, dan badge dapat diubah.

MENJALANKAN:
1. Extract ZIP.
2. Buka index.html di browser.
3. Disarankan memakai VS Code + Live Server.
